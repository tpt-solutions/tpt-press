# Security Policy

## Supported versions

tpt-press is pre-1.0. Only the latest released version receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for security problems, especially those
involving parsing of untrusted archive files (memory-safety, out-of-bounds reads,
decompression bombs, path traversal on unpack).

Report privately to TPT Solutions through the repository's GitHub
**Security → Report a vulnerability** form. We aim to acknowledge reports within
five business days.
